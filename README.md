# Impacto Manager V2

Versão funcional local para a IMPACTO OBU.

## Funcionalidades
- Login local do administrador
- Dashboard
- Cadastro e edição de alunos
- Controle manual de presença
- Controle de mensalidades
- Busca de alunos
- Exportação e importação de backup

## Publicação no GitHub Pages

1. Apague os arquivos antigos do repositório.
2. Extraia este ZIP.
3. Envie:
   - index.html
   - pasta css
   - pasta js
4. Faça Commit changes.
5. Abra:
   https://impactoobu.github.io/impacto-obu-system/?v=500

## Importante

Os dados ficam salvos no navegador do aparelho.
Use o botão "Exportar backup" regularmente.
